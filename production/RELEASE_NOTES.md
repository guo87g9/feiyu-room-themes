# v3.1.0-remix 发布说明（定稿）

> 仓库：[`guo87g9/feiyu-room-themes`](https://github.com/guo87g9/feiyu-room-themes) · 状态：定稿 · 发布日期：待 go/no-go 通过后填写
> 性质：**独立新建的公开仓库**，代码与户型取自 [`sh2234113/feiyu-room-template`](https://github.com/sh2234113/feiyu-room-template)，在其上做视觉二创；不是新项目，也不是任何厂商的官方版本。

先说清楚这个仓库是什么：它是基于上游 `feiyu-room-template` 做的一次**视觉二创**，只换房间配色，并做了一次**资产层精简**。**玩法一项没动** —— 户型、家具、菜园、电视投屏、房间私聊、QQ 桥接、本地控制台全都还在，和上游一样能用。

这次主要做了两件事：给同一间房加了 4 套可切换的配色主题；把不便随开源仓库分发的**资产文件**（作者自制的 3D 模型、第三方安装包）移除干净。仅此而已，没有砍功能。

**它不是原创房间**，也不隶属于 DeepSeek、SnowLuma、腾讯或 QQ 官方。房间氛围与「和角色一起生活」的交互灵感来源写在 [`INSPIRATION.md`](../INSPIRATION.md)，二次发布请一并保留，不要改写成自有创作。

## 新增：4 套可切换的房间主题

| UI 名称 | 配置 key | 说明 |
| --- | --- | --- |
| 蓝白小屋 | `blue_white` | **默认主题**，冷白底 + 藏青结构，呼应 2D 立绘的蓝发配色 |
| 海边小屋 | `seaside` | 暖白 + 浅木 + 海玻璃青，明亮松弛 |
| 森林木屋 | `forest` | 深木棕 + 苔绿 + 炉火橙，暖光包裹感 |
| 中式小院 | `courtyard` | 粉墙留白 + 青砖深木 + 一点朱砂，取「院」之意、不取「院」之形 |

- 一键切换，选择保存在浏览器本地，刷新后还在；不需要账号，也不写入服务端。
- **只改材质配色、灯光色调和窗外氛围**：户型、家具位置与碰撞、寻路点、交互热区、菜园数值、聊天与投屏逻辑、角色动作表全部不变。
- 4 套主题没有数值收益、没有解锁条件，纯粹是审美偏好；低照度的「森林木屋」按 **Standard 可访问性分级**做了对比度兜底，不让人找不到可点的地方。
- **4 套锁死，本轮不加第 5 套**；默认 `blue_white`。
- 主题名沿用上游 `HOUSE_GENERATION_PROMPT.md` 里已有的风格方向，但在这里是**同一户型换配色**（上游「方式 A」的视觉子分支），不是让 DSH 从零生成一栋新房子（方式 B），两者不要混着用。

## 移除内容

> **作者 3D 模型与第三方安装包已移除，本仓库不含任何 3D 模型文件。**

精确一点说，避免误解：

- **不含任何角色 3D 模型文件／私人素材；保留的 2D 立绘是已署名的第三方 CC 素材。** 上游模板里作者提供的 3 个 `.glb` 模型文件（优化展示版与 58.9 MB 原始工程备份）已从本仓库彻底移除，不保留任何形式的副本，也不提供下载链接。该模型版权归作者，二创 / 再分发需要书面许可，本仓库未取得该许可，不主张这项权利，也不把它写成 MIT 或任何开源许可。
- `tools/` 目录下的第三方安装包（暴喵AI管家 Windows / macOS 安装程序）整目录移除，不提供安装包、下载链接、邀请码、返利或领取活动，也不沿用任何「已获官方授权分发」的表述。
- 「不含任何 3D 模型文件」指的是**没有 `.glb` / `.gltf` 一类的模型资产文件**；房间的三维场景本身就是 Three.js 的程序化几何与材质，代码一直都在，**3D 模式也还在**（见下节）。
- 移除后仓库体积明显变小，clone 和首次打开都更轻，也不需要再为「某个文件能不能公开」纠结。

**这里只有资产文件的移除，没有任何功能删减。** 菜园、QQ 桥接、电视投屏、房间私聊、控制台照旧。

## 3D 模式改为程序化角色兜底

- 模型文件移除后，**切到 3D 模式时角色由 `actor3d.js` 的代码级程序化几何呈现**，不再加载成品 GLB；3D 模式本身保留，加载失败会回落到 2D 立绘，不会卡住或白屏。
- 这是**代码里的几何体**，不是模型资产文件，随代码按 MIT 提供；它和已移除的 3 个作者 GLB 不是一回事。
- 上游文档里「6.7 MB 标准 / 58.9 MB 高画质」的「画质」切换按钮和对应文案已随本次改动移除或改写，请不要再按老截图去找它。
- 说句实在话：**拟真度是下降的**。成品模型不在了，陪伴感更多由 2D 立绘和房间氛围承担。如果你是按上游演示视频里那个精细模型来的，这里会和你预期不一样，先打个招呼。
- 2D 立绘 / 动画 / 点击音效沿用第三方项目 dsh-pet 的**原素材**，未重绘、未改一个像素，署名照旧保留在页面底部。

- **悬空 npm scripts**：`voice-gui` / `voice-cli` 指向不存在的 `../voice-tool`，已清理；并全量核对了 `package.json` 里脚本引用的文件是否真实存在，保证 `npm ci` 之后验收命令跑得起来。
- **README 路径与失效条目**：删除指向已移除 `tools/README.md` 的链接、6.7/58.9 MB 画质条目和「附带作者展示模型」等过期表述，补齐相对链接与主题切换说明。

- 同步更新了 `THIRD_PARTY_NOTICES.md`、`PRIVACY_AND_ASSETS.md`、`SETUP.md`、`START_HERE.txt` 等文档，让文字和实际内容对得上，不再出现「文档说有、仓库里没有」的情况。

## 已知限制

- **3D 模式是程序化几何角色，不是成品模型**，细节和观感有限；追求拟真的话可能会失望。
- **4 套主题只改视觉**，不新增家具、玩法、户型或作物；「中式小院」取的是氛围，不会真的多出一个院落。
- **主题选择存在浏览器本地**：换浏览器、清缓存、隐私模式下会回到默认「蓝白小屋」，不会白屏或报错，但也不会跨设备同步。
- **2D 立绘受 CC BY-NC-SA 4.0 约束**：仅限非商业、改动素材需按相同方式共享；这一条不因换皮而改变。本仓库不提供商用路径。
- **运行环境仍需自备**：Node.js >= 22.13、DeepSeek Harness、以及可选的 SnowLuma 都不在本仓库内分发；首次使用要自行配置 `config.json`。
- **依赖存在已知漏洞（如实披露）**：quality-lead 实跑 `npm ci` 报告 **9 个依赖漏洞（5 moderate / 3 high / 1 critical）**，来自上游锁定的依赖版本。本轮**不擅自升级依赖** —— 升级会破坏当前 DSH `0.2.1-rc.2` 协议适配，风险高于收益；建议后续单独开 issue 评估升级方案。**使用者请自行评估依赖风险**后再决定是否部署。
- **不含任何私人内容**：角色卡、私人记忆、聊天记录、QQ 号 / 群号、API Key、语音、照片都没有，`config.json` / `state/` / `audio/` / `assets/` 也不入库。
- **测试覆盖有边界（如实披露）**：`npm run test:*` 全量 7 条已在 Windows 实跑 `EXIT=0`，但**没有做真实浏览器的 WebGL 像素级/截图验证** —— 本机无浏览器环境。色彩对比度是按 WCAG 2.1 公式静态复算的，不等于你屏幕上的观感。若发现某套主题在特定显示器上不理想，欢迎带截图提 Issue。
- **低照度主题的可读性**按 Standard 分级做了兜底，但仍在观察中：如果觉得「森林木屋」下按钮不够醒目，欢迎提 Issue，我们会优先看对比度而不是加特效。
- **本仓库不是上游的官方续作**，也不接受以上游名义提出的功能预期；问题与建议请发到本仓库 Issues。
